# 怎么构造 Portfolio

组合构建不是先挑一个优化器，而是把**目标、数据、约束、配置、验证和执行**连成一条可复现的流程。

## 1. 先定义投资任务

在计算权重前写清楚：

1. **目标**：绝对收益、相对基准收益、最低波动，还是目标风险；
2. **投资期限**：日内、月度、年度或更长；
3. **风险预算**：可接受波动率、最大回撤和杠杆；
4. **约束**：是否允许做空、单资产上限、行业上限、最低现金比例和换手率上限；
5. **执行规则**：再平衡频率、交易成本、最小交易单位和流动性要求。

目标和约束应该能够写成可以检查的数字。例如：“年化波动率不超过 10%，单资产权重不超过 20%，不做空，每月最后一个交易日再平衡”。

## 2. 建立可投资资产池

资产池应由策略在当时真正可以买到的标的组成。筛选时至少考虑：

- 上市和退市日期，避免生存者偏差；
- 成交量、买卖价差和容量；
- 资产类别、行业、地区与币种暴露；
- 数据质量和足够长的历史记录；
- 基金费率、借券成本与税费。

不要用今天的成分股名单直接回测过去。每个回测时点只能使用当时已知的信息。

## 3. 估计收益与风险

若价格为 \(P_{i,t}\)，简单收益率可写为：

\[
r_{i,t}=\frac{P_{i,t}}{P_{i,t-1}}-1
\]

组合在一期内的收益近似为 \(r_{p,t}=w_t^\top r_t\)。构造权重通常需要：

- 预期收益向量 \(\mu\)；
- 协方差矩阵 \(\Sigma\)；
- 当前权重 \(w_{old}\)，用于控制换手。

预期收益噪声很大。实践中可以从等权或风险配置开始，再逐步加入动量、价值、carry 等信号。协方差建议使用滚动窗口并进行收缩，避免样本过少时矩阵不稳定。所有估计都必须只使用再平衡日之前的数据。

## 4. 选择权重方法

### 等权：可靠的基线

对 \(N\) 个资产设置 \(w_i=1/N\)。它简单、透明，适合作为其他方案必须击败的基准，但没有显式控制各资产的风险贡献。

### 逆波动率：不依赖预期收益

令资产波动率为 \(\sigma_i\)：

\[
w_i=\frac{1/\sigma_i}{\sum_j 1/\sigma_j}
\]

这种方法会降低高波动资产的权重。它实现容易，但忽略了资产之间的相关性；完整的风险平价应同时使用协方差矩阵。

### 均值—方差：显式权衡收益和风险

一个常见目标是：

\[
\max_w\quad \mu^\top w-\frac{\lambda}{2}w^\top\Sigma w
\]

同时加入约束，例如：

\[
\sum_iw_i=1,\quad 0\leq w_i\leq 20\%
\]

其中 \(\lambda\) 表示风险厌恶。若加入交易成本，可在目标中减去与 \(|w-w_{old}|\) 有关的惩罚项。优化结果若频繁顶到约束边界，通常意味着输入不稳定或约束需要重新审视，而不一定代表发现了强信号。

## 5. 一个可执行的起点

首次实现时可以采用下面的最小方案：

1. 选择流动性合格且有足够历史数据的资产；
2. 用过去 60 至 252 个交易日估计波动率；
3. 计算逆波动率权重；
4. 把单资产权重限制在预设上限，并重新归一化；
5. 根据目标组合波动率决定是否整体缩放风险仓位；
6. 每月再平衡，仅在目标权重与当前权重的差异超过阈值时交易；
7. 把未投资部分保留为现金，不为满足满仓而强行加仓。

示意伪代码：

```python
volatility = returns.rolling(120).std().iloc[-1]
raw_weight = 1 / volatility
weight = raw_weight / raw_weight.sum()
weight = cap_and_normalize(weight, max_weight=0.20)
orders = create_orders(current_weight, weight, no_trade_band=0.01)
```

生产实现还需要处理缺失值、停牌、极低波动率、权重上限不可行、现金和交易单位等边界情况。

## 6. 正确回测

回测应采用 walk-forward 流程：在再平衡日 \(t\) 用截至 \(t\) 的数据产生权重，在之后的持有期应用该权重。至少计入：

- 手续费、买卖价差和市场冲击；
- 信号与成交之间的延迟；
- 分红、拆股、退市和币种换算；
- 实际可成交价格，而不是产生信号时已经知道的收盘价；
- 因权重变化产生的换手成本。

除年化收益外，还应报告波动率、Sharpe、最大回撤、换手率、集中度、最差时期表现，以及相对基准的跟踪误差。样本外结果和参数敏感性比单一的最佳回测更重要。

## 7. 上线前检查表

- [ ] 目标、基准和风险预算有明确数字；
- [ ] 数据不存在前视偏差和生存者偏差；
- [ ] 权重之和、上下限、杠杆和行业约束每天都可验证；
- [ ] 成本假设经过压力测试；
- [ ] 参数在邻近取值下仍然有效；
- [ ] 有样本外或纸面交易记录；
- [ ] 有数据缺失、异常行情和下单失败的处理方案；
- [ ] 有监控、告警、人工停机和回滚流程。

## 8. 如何选择第一版

- **没有稳定收益预测**：先用等权或逆波动率；
- **强调分散风险**：使用包含相关性的风险预算方法；
- **有经过样本外验证的收益预测**：再考虑带约束和成本惩罚的均值—方差优化；
- **需要追踪基准**：优化主动权重，并约束跟踪误差、行业和风格暴露。

第一版应尽量简单。先建立不会泄漏未来信息、能计算真实交易成本的回测，再增加复杂模型；否则优化器往往只是在放大估计误差。
